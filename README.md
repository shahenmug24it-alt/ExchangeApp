# ExchangeApp

An Android application for buying, selling, and exchanging products.

## Features

- User Registration and Login
- Add Products
- Browse Products
- Send Exchange Requests
- View My Requests
- Logout

## Technologies Used

- Java
- Android Studio
- XML
- Firebase

## Project Description

ExchangeApp is a simple mobile application that allows users to list products, browse available products, and send requests to exchange products.
